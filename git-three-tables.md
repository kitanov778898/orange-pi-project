# GIT: МОДЕЛЬ ТРЁХ СТОЛОВ
## Справочник для понимания работы Git

================================================================================
📖 ШПАРГАЛКА: СМАЙЛИКИ И ИХ ЗНАЧЕНИЯ
================================================================================

🏗️ ТРИ СТОЛА GIT (основная модель)
--------------------------------------------------------------------------------
🪑 Working Directory (Рабочий стол)
   • Твоя рабочая папка с файлами
   • Здесь ты пишешь, стираешь, копируешь
   • Аналогия: твой письменный стол

📋 Index / Staging Area (Стол подготовки)
   • Зона подготовки изменений
   • Сюда кладёшь файлы, которые хочешь заархивировать
   • Аналогия: папка «На подпись»

📦 Repository / Commit (Архив)
   • История изменений (коммиты)
   • Зафиксированные снимки проекта
   • Аналогия: сейф с архивами (нельзя изменить)

================================================================================
🔧 ОСНОВНЫЕ КОМАНДЫ И ИХ ДЕЙСТВИЕ
================================================================================

Команда                          | Что делает              | Движение
---------------------------------|-------------------------|------------------
git add <файл>                   | Готовит файл к коммиту  | 🪑 → 📋
git commit -m "сообщение"        | Сохраняет снимок        | 📋 → 📦
git checkout -- <файл>           | Отменяет изменения      | 📦 → 🪑 (замена)
git status                       | Показывает состояние    | 🔍 сканирует всё
cp <от> <куда>                   | Копирует файл           | Только на 🪑
mv <от> <куда>                   | Перемещает файл         | Только на 🪑
git mv <от> <куда>               | Переименовывает для Git | 🪑 →  (сразу)

================================================================================
📊 ЧТО ПОКАЗЫВАЕТ GIT STATUS
================================================================================

Вывод команды                          | Что на столах
---------------------------------------|----------------------------------
nothing to commit,                     | 🪑 =  (совпадают)
working directory clean                | 📋 пуст
---------------------------------------|----------------------------------
Changes not staged for commit:         | На 🪑 есть изменения,
  modified: файл.txt                   | которых нет на 📋
---------------------------------------|----------------------------------Changes to be committed:               | На 📋 лежат файлы,
  modified: файл.txt                   | готовые к коммиту
---------------------------------------|----------------------------------
Untracked files:                       | На 🪑 лежат файлы,
  новый_файл.txt                       | о которых Git не знает

================================================================================
🎯 КРИТЕРИЙ «ЧИСТОГО» СОСТОЯНИЯ
================================================================================

git status показывает:
  "nothing to commit, working directory clean"

Это означает:
  ✅ 🪑 Рабочий стол полностью совпадает с 📦 Архивом
  ✅ 📋 Стол подготовки ПУСТ
  ✅ Нет незнакомых файлов

================================================================================
🔍 АЛГОРИТМ АНАЛИЗА ЗАДАНИЯ
================================================================================

Шаг 1. Определи начальное состояние
   • git status №0: "nothing to commit, working directory clean"
   • Вывод: все столы в порядке

Шаг 2. Разбери каждую команду в варианте
   • echo >> файл     → изменение на 🪑
   • git add файл     → перенос с 🪑 на 📋
   • git checkout --  → замена 🪑 копией из 📦
   • cp файл          → новый файл на 🪑 (неизвестен Git)
   • git mv файл      → перемещение с записью на 📋

Шаг 3. Проверь конечное состояние
   • После всех команд вызови мысленно git status
   • Спроси: 🪑 = ? 📋 пуст?
   • Если ДА → это правильный ответ

================================================================================
📝 ПРИМЕР РАЗБОРА ВАРИАНТОВ
================================================================================

ВАРИАНТ A:
  1. echo ww >> ./man/spring/word/popcorn.file
     → Изменили файл на 🪑
     → git status: "Changes not staged for commit"
  
  2. git checkout -- ./man/spring/word/popcorn.file
     → Взяли оригинал из 📦 и заменили им файл на 🪑
     → 🪑 снова = 📦, 📋 пуст     → git status: "nothing to commit, working directory clean"
  
  ✅ ВАРИАНТ A ВОЗВРАЩАЕТ ЧИСТОЕ СОСТОЯНИЕ

ВАРИАНТ B:
  1. echo ww >> ./man/spring/word/popcorn.file
     → Изменили файл на 🪑
  
  2. git add ./man/spring/word/popcorn.file
     → Перенесли изменение с 🪑 на 📋
     → 📋 НЕ пуст!
     → git status: "Changes to be committed"
  
  ❌ ВАРИАНТ B НЕ ВОЗВРАЩАЕТ ЧИСТОЕ СОСТОЯНИЕ

ВАРИАНТ C:
  1. cp ./man/spring/word/popcorn.file ./tztfu
     → Создали копию на 🪑
     → Git не знает этот файл
     → git status: "Untracked files: ./tztfu"
  
  2. git mv ./man/spring/word/popcorn.file ./flag.file
     → Переименовали и положили на 📋
     → 📋 НЕ пуст!
     → git status: "Changes to be committed" + "Untracked files"
  
  ❌ ВАРИАНТ C НЕ ВОЗВРАЩАЕТ ЧИСТОЕ СОСТОЯНИЕ

================================================================================
💡 КЛЮЧЕВЫЕ ВЫВОДЫ
================================================================================

1. git add НЕ отменяет изменения — он готовит их к коммиту
2. git checkout -- ОТМЕНЯЕТ изменения, возвращая файл к версии из архива
3. Обычные cp/mv невидимы для Git до команды git add
4. «Чисто» = 🪑 совпадает с 📦 И 📋 пуст
5. Любое изменение на 📋 или 🪑 нарушает чистоту
